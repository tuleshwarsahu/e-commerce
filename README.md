Mini E-Commerce Dashboard

Overview

This project is a Mini E-Commerce Dashboard built using Python and Django. It displays product details, generates sales graphs, and visualizes category-wise product sales using Matplotlib and Pandas. The sales data is stored in the default SQLite3 database, and users can analyze sales based on date ranges.

Features

Sales Graphs: Visual representation of product sales.
Category-Wise Graphs: Displays category-wise distribution of products.
Date-Based Sales Analysis: Analyze sales trends using date filters.

Technologies Used

Programming Language: Python
Framework: Django
Database: SQLite3 (default Django database)
Visualization Libraries: Matplotlib, Pandas

Installation & Setup

Prerequisites
Ensure you have the following installed:

Python (>= 3.10)
Django (>= 4.0)

SQLite3 (included with Python)
